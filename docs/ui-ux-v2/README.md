# UI/UX SpaSmooTh V2

Esta pasta registra o redesenho da interface pública sem alterar o fluxo de agendamento, a camada de dados, SEO técnico ou o painel administrativo.

## Escopo

- Home, navegação, catálogo de serviços, equipe, localização, cookies, WhatsApp e confirmação de solicitação.
- Responsividade de 360 px a desktop amplo.
- Uso de dados existentes: serviços, profissionais, unidades e horários continuam vindo das integrações atuais.

## Fora de escopo

- Alterações de schema, migrations, regras de slots, preços, dados de clientes, deploy e merge.
- Publicação de depoimentos sem fonte verificável.

## Documentos

- `audit-before.md`: fotografia técnica antes da intervenção.
- `design-system.md`: tokens e regras visuais.
- `image-plan.md`: origem, intenção e fallback dos assets.
- `responsive.md`: critérios por viewport e acessibilidade.
- `cookie-consent.md`: comportamento de consentimento.
- `implementation-report.md`: alterações e validações desta branch.
